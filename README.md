# 3DS-Chunker-Ultimate-GUI
A world converter for Minecraft: Java Edition to Minecraft: New Nintendo 3DS Edition.
This fork has been improved to convert worlds from at least Java 1.13.2 to MC3DS with near-perfect accuracy. Item conversion is also possible.
**Some of the code is GPT 5 Assisted.**

# Features
- Added MCPE 1.1.5 <=> New 3DS world convertion with Host Player data!
- Inproved Java => New 3DS World Convertion.
